# Third-party notices

Cameo is MIT licensed. Code adapted from other projects keeps their copyright notices here. Each entry names the files it went into.

No code has been adapted from other projects.

`scripts/mark.js` carries over the name-matching approach from Threadwork's `scripts/emblem.js` (https://github.com/NidhCthon/threadwork), which is the same author's work under the same MIT licence, so it needs no separate notice. The tinting is new: a frame casts its symbol in metal through an SVG filter rather than recolouring pixels on a canvas.

## Fonts

The banderole's lettering ships as one typeface in `styles/fonts/`, under the SIL Open Font License 1.1, whose full text is beside it:

- **Cinzel**, copyright 2020 The Cinzel Project Authors (https://github.com/NDISCOVER/Cinzel). `OFL-Cinzel.txt`.

The files are the latin and latin-ext variable WOFF2 builds from Fontsource (`@fontsource-variable/cinzel`, 5.3.0), unmodified.

## Symbols

Cameo ships no symbols of any kind. It reads a folder in your own world's `Data/`. Whatever you put there is yours to be licensed for, and artwork licensed for use at your own table usually cannot be redistributed, so keep it out of this repository.
